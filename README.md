## Описание

Программно-аппаратный комплекс для автоматизации обслуживания очереди в организациях. Устраняет живые очереди, оптимизирует нагрузку на операторов, собирает аналитику.

## Структура проекта

| Папка / Файл | Задание | Описание |
|---|---|---|
| `backend/` | Задание 4 | Ядро системы: база данных, API администратора и оператора |
| `kiosk/` | Задание 5 | Модуль киоска — получение талона |
| `display/` | Задание 5 | Модуль дисплея — экран зоны ожидания |
| `mobile/` | Задание 6 | Мобильный интерфейс для клиента |
| `reports/` | Задание 6 | Модуль отчётности администратора |
| `app.py` | Задание 4 | Точка входа Flask-приложения |

## Запуск

```bash
pip install flask
python app.py
```

Сервер запустится на `http://localhost:5000`

## Технологии

- **Backend:** Python 3, Flask, SQLite
- **Frontend:** HTML5, CSS3, JavaScript
